## 🎯 هدف نرم‌افزار
کار این برنامه تبدیل سریع ساعت است: **ساعت ورودی را به آن می‌دهید، ساعت تبدیل‌شده را تحویل می‌دهد و تمام.**

در فعالیت‌های روزمره، تعیین زمان پایان کار، محاسبه شیفت‌ها، اضافه/کسر زمان و تبدیل ساعت‌ها نیاز به یک ابزار دم دست و بی‌دردسر دارد.  
با **Clock Plus** نیازی به محاسبه ذهنی یا کلیک‌های اضافی ندارید:  
ساعت را کپی می‌کنید، با `Ctrl+V` وارد برنامه می‌شود، مقدار ثابت به آن افزوده یا کاسته می‌شود، و با `Ctrl+C` ساعت جدید کپی شده و آماده پیست در هر برنامه‌ای است.

## ⚡ گردش کار سریع تبدیل ساعت (Workflow)

```text
┌─────────────────┐       Ctrl + C       ┌─────────────────┐
│ هر متن یا برنامه│ ──────────────────> │ کلیپ‌بورد سیستم │
└─────────────────┘                     └─────────────────┘
                                                  │
                                                  │ Ctrl + V (یا راست‌کلیک)
                                                  ▼
                                        ┌─────────────────┐
                                        │   Clock Plus    │
                                        │  (تبدیل آنی)    │
                                        └─────────────────┘
                                                  │
                                                  │ Ctrl + C (یا کلیک روی نتیجه)
                                                  ▼
┌─────────────────┐       Ctrl + V       ┌─────────────────┐
│  برنامه مقصد    │ <────────────────── │ کلیپ‌بورد سیستم │
└─────────────────┘                     └─────────────────┘
```

1. در هر محیطی ساعت موردنظر را کپی کنید (`Ctrl+C`).
2. در پنجره **Clock Plus** کلید `Ctrl+V` (یا کلیک‌راست) بزنید:
   - ساعت دریافت شده و فوراً با مقدار تنظیمی تبدیل می‌شود.
3. کلید `Ctrl+C` را بزنید تا ساعت تبدیل‌شده کپی شود.
4. در مقصد موردنظر `Ctrl+V` بزنید.

## ✨ ویژگی‌های کلیدی

### ۱. استقلال کامل از زبان کیبورد ویندوز
چه زبان کیبورد ویندوز فارسی (`FA`) باشد چه انگلیسی (`EN`)، میانبرهای `Ctrl+V` و `Ctrl+C` بر اساس **کد سخت‌افزاری فیزیکی کلید (Hardware Keycode)** عمل می‌کنند و بدون نقص کار می‌کنند.

### ۲. طراحی بصری مدرن با گوشه‌های گرد (Rounded UI)
- تمامی کارت‌ها، دکمه‌ها و فیلدهای ورودی دارای لبه‌های نرم و گرد (`radius=10px` تا `18px`) هستند.
- رندرینگ آنتی‌الیاسینگ (Anti-Aliasing) دو مرحله‌ای با Pillow مانع از هرگونه دندانه‌دار شدن خطوط می‌شود.
- فیلدهای ارقام دارای کادرهای اختصاصی خمیده (Curved Slots) با هایلایت فوکوس نئونی هستند.

### ۳. کنتراست بالای ارقام در حالت دارک و لایت
- ارقام در تم تاریک با رنگ سفید خالص (`#FFFFFF`) با وضوح بالا روی پس‌زمینه سورمه‌ای تیره (`#202036`) نمایش داده می‌شوند.
- در حالت انتخاب (Selection)، متن با هایلایت نئونی مشخص می‌شود تا خوانایی حفظ شود.

### ۴. آیکون‌های وکتور اختصاصی
- آیکون‌های تغییر تم (خورشید و ماه) و آیکون پین پنجره به صورت برداری و در زمان اجرا با Pillow تولید می‌شوند و هیچ وابستگی به تصاویر جانبی ندارند.

### ۵. پین کردن پنجره (Always on Top)
- با کلیک روی آیکون پین، پنجره Clock Plus روی سایر برنامه‌ها ثابت می‌ماند تا هنگام کار به زیر پنجره‌های دیگر نرود.

### ۶. حفظ ابعاد و موقعیت مکانی پنجره
- اندازه و مختصات قرارگیری پنجره روی مانیتور در زمان خروج در فایل `timecalc_settings.json` ذخیره می‌شود و در اجرای بعد دقیقاً در همان موقعیت باز می‌گردد.

### ۷. پشتیبانی از مانیتورهای High-DPI
- با فعال‌سازی Per-Monitor DPI Awareness V2 در سطح هسته ویندوز، تمامی متون و خطوط در مانیتورهای ۴K و اسکیل‌های ۱۲۵٪ یا ۱۵۰٪ کاملاً شفاف هستند.

## ⌨️ جدول کلیدهای میانبر و فرمان‌ها

| میانبر / کنترل | عملکرد |
| :--- | :--- |
| **Ctrl + V** | دریافت آنی ساعت از کلیپ‌بورد، درج در فیلدها و انجام تبدیل لحظه‌ای |
| **راست‌کلیک** | معادل Ctrl+V در هر کجای پنجره برنامه برای پیست سریع |
| **Ctrl + C** | کپی کردن ساعت تبدیل‌شده نهایی در کلیپ‌بورد |
| **کلیک روی کادر نتیجه** | کپی سریع نتیجه ساعت تبدیل‌شده |
| **Enter** | انجام تبدیل |
| **Esc** | بستن سریع برنامه |
| **دکمه الان** | ثبت ساعت و دقیقه فعلی سیستم در فیلدهای ساعت پایه |
| **دکمه Paste** | کلید دستی جایگزین برای خواندن کلیپ‌بورد |
| **آیکون خورشید / ماه** | جابجایی بین حالت شب (Dark Mode) و حالت روز (Light Mode) |
| **آیکون پین** | سنجاق کردن پنجره روی سایر برنامه‌ها (Always on Top) |
| **چرخ ماوس روی فیلدها** | افزایش یا کاهش ۱ واحدی ساعت یا دقیقه |
| **کلیدهای جهت‌نما (↑ / ↓)** | افزایش یا کاهش عدد فیلد انتخابی با چرخه ۲۴ ساعته و ۶۰ دقیقه‌ای |
| **Auto-Tab** | پرش خودکار به فیلد دقیقه پس از تایپ دو رقم در بخش ساعت |

## 🕒 فرمت‌های زمانی پشتیبانی‌شده

پارسر برنامه به صورت خودکار انواع فرمت‌های متنی و زبان‌ها را شناسایی و پالایش می‌کند:

| متن کپی‌شده | نحوه تفسیر در Clock Plus |
| :--- | :--- |
| `14:30:00` | ساعت `14` و دقیقه `30` (ثانیه نادیده گرفته می‌شود) |
| `14:30` | ساعت `14` و دقیقه `30` |
| `14-30` یا `14/30` یا `14.30` | ساعت `14` و دقیقه `30` |
| `02:30 PM` یا `02:30 ب.ظ` | تبدیل خودکار به فرمت ۲۴ ساعته: `14:30` |
| `08:15 AM` یا `08:15 ق.ظ` | ساعت `08` و دقیقه `15` |
| `1430` | ساعت `14` و دقیقه `30` (اعداد ۴ رقمی به هم چسبیده) |
| `915` | ساعت `09` و دقیقه `15` (اعداد ۳ رقمی به هم چسبیده) |
| `۱۶:۴۵` | تبدیل ارقام فارسی به انگلیسی: ساعت `16` و دقیقه `45` |
| `+01:30` | تنظیم خودکار بخش «مقدار اضافه» روی `+01:30` و تبدیل آنی |
| `-00:45` | تنظیم خودکار بخش «مقدار اضافه» روی `-00:45` (کسر زمان) و تبدیل آنی |

## ⚙️ پایداری و تنظیمات (timecalc_settings.json)

تنظیمات برنامه در یک فایل سبک JSON کنار فایل اجرایی ذخیره می‌شود:

```json
{
  "theme": "dark",
  "add_hour": "1",
  "add_minute": "30",
  "geometry": "560x720+595+115"
}
```

- **theme:** وضعیت تم فعال (`dark` یا `light`).
- **add_hour:** مقدار ساعت ثابتی که باید اضافه یا کم شود (پشتیبانی از اعداد منفی).
- **add_minute:** مقدار دقیقه ثابت افزایشی.
- **geometry:** آخرین مختصات قرارگیری و ابعاد پنجره روی دسکتاپ.

## 🔨 راهنمای کامپایل و بیلد با PyInstaller

اگر سورس‌کد `clock.py` را تغییر دادید و مایلید فایل اجرایی پورتابل جدید بسازید:

### پیش‌نیازها:
```bash
pip install pillow pyperclip pyinstaller
```

### دستور بیلد تک‌فایل مستقل:
```bash
python -m PyInstaller   --noconsole   --onefile   --icon="icon.ico"   --add-data="icon.ico;."   --name="ClockPlus"   --clean   clock.py
```

- خروجی نهایی: `ClockPlus.exe`
- حجم فایل اجرایی نهایی: حدود ۱۶ مگابایت (شامل مفسر کامل پایتون، Tkinter و کتابخانه‌ها به صورت تک‌فایل بدون نیاز به نصب).
