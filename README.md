## 🎯 چرا Clock Plus؟
در محاسبات روزمره، تعیین دقیق ساعت‌های کاری، شیفت‌ها، اضافه‌کاری، اختلاف افق زمانی و تبدیل ساعت‌ها همواره نیازمند جابجایی و تبدیل زمان است. تبدیل دستی یا استفاده از روش‌های سنتی وقت‌گیر است و خطای انسانی به همراه دارد.

**Clock Plus** این فرآیند را به یک چرخه آنی بدون نیاز به حتی یک کلیک ماوس تبدیل می‌کند:
ساعت را در اکسل کپی می‌کنید، در Clock Plus کلید `Ctrl+V` می‌زنید، محاسبه در همان لحظه انجام می‌شود، با `Ctrl+C` نتیجه کپی می‌شود و مستقیماً در اکسل پیست می‌کنید.

## ⚡ گردش کار سریع با اکسل (Workflow)

```text
┌─────────────────┐       Ctrl + C       ┌─────────────────┐
│  سلول اکسل       │ ──────────────────> │ کلیپ‌بورد سیستم │
└─────────────────┘                     └─────────────────┘
                                                  │
                                                  │ Ctrl + V (یا راست‌کلیک)
                                                  ▼
                                        ┌─────────────────┐
                                        │   Clock Plus    │
                                        │ (محاسبه خودکار) │
                                        └─────────────────┘
                                                  │
                                                  │ Ctrl + C (یا کلیک روی نتیجه)
                                                  ▼
┌─────────────────┐       Ctrl + V       ┌─────────────────┐
│  سلول مقصد اکسل  │ <────────────────── │ کلیپ‌بورد سیستم │
└─────────────────┘                     └─────────────────┘
```

1. در فایل اکسل، سلول ساعت موردنظر را انتخاب و `Ctrl+C` بزنید.
2. پنجره **Clock Plus** را باز کرده و `Ctrl+V` (یا کلیک‌راست) بزنید:
   - ساعت در فیلد پایه قرار گرفته و بلافاصله با مقدار افزایشی جمع/تفریق می‌شود.
3. کلید `Ctrl+C` را بزنید (پیام تایید سبز رنگ ظاهر می‌شود).
4. به اکسل برگشته و در سلول مقصد `Ctrl+V` بزنید.

## ✨ ویژگی‌های کلیدی

### ۱. استقلال کامل از زبان کیبورد ویندوز
بسیاری از ابزارهای پایتونی هنگام فارسی بودن کیبورد ویندوز، کلیدهای میانبر `Ctrl+V` و `Ctrl+C` را تشخیص نمی‌دهند (زیرا حروف «ر» و «و» ارسال می‌شوند). در Clock Plus، رخدادها بر اساس **کد سخت‌افزاری فیزیکی کلید (Hardware Keycode)** خوانده می‌شوند و در هر دو زبان انگلیسی و فارسی ۱۰۰٪ بدون خطا کار می‌کنند.

### ۲. طراحی بصری مدرن با گوشه‌های گرد (Rounded UI)
- تمامی کارت‌ها، دکمه‌ها و فیلدهای ورودی دارای لبه‌های نرم و گرد (`radius=10px` تا `18px`) هستند.
- رندرینگ آنتی‌الیاسینگ (Anti-Aliasing) دو مرحله‌ای با Pillow مانع از هرگونه دندانه‌دار شدن خطوط می‌شود.
- فیلدهای ارقام دارای کادرهای اختصاصی خمیده (Curved Slots) با هایلایت فوکوس نئونی هستند.

### ۳. کنتراست بالای ارقام در حالت دارک و لایت
- ارقام در تم تاریک با رنگ سفید خالص (`#FFFFFF`) با وضوح فوق‌العاده روی پس‌زمینه سورمه‌ای تیره (`#202036`) نمایش داده می‌شوند.
- در حالت انتخاب (Selection)، متن با هایلایت نئونی مشخص می‌شود تا زیر پس‌زمینه پنهان نگردد.

### ۴. آیکون‌های وکتور اختصاصی
- آیکون‌های تغییر تم (خورشید و ماه) و آیکون پین پنجره به صورت برداری و با روابط مثلثاتی ریاضی در زمان اجرا تولید می‌شوند و هیچ وابستگی به تصاویر خارجی ندارند.

### ۵. پین کردن پنجره (Always on Top)
- با کلیک روی آیکون پین، پنجره Clock Plus روی سایر برنامه‌ها ثابت می‌ماند تا هنگام کار همزمان با اکسل به زیر پنجره‌های دیگر نرود.

### ۶. حفظ ابعاد و موقعیت مکانی پنجره
- اندازه و مختصات قرارگیری پنجره روی مانیتور در زمان خروج در فایل `timecalc_settings.json` ذخیره می‌شود و در اجرای بعد دقیقاً در همان موقعیت باز می‌گردد.

### ۷. پشتیبانی از مانیتورهای High-DPI
- با فعال‌سازی Per-Monitor DPI Awareness V2 در سطح هسته ویندوز، تمامی متون و خطوط در مانیتورهای ۴K و اسکیل‌های ۱۲۵٪ یا ۱۵۰٪ کاملاً شفاف و شارپ هستند.

| میانبر / کنترل | عملکرد |
| :--- | :--- |

| **راست‌کلیک** | معادل Ctrl+V در هر کجای پنجره برنامه برای پیست سریع |
| **Ctrl + C** | کپی کردن نتیجه نهایی ساعت در کلیپ‌بورد برای پیست در اکسل |
| **کلیک روی کادر نتیجه** | کپی سریع نتیجه ساعت تبدیل‌شده |
| **Enter** | انجام دستی محاسبه |
| **Esc** | بستن سریع برنامه |
| **دکمه الان** | ثبت ساعت و دقیقه فعلی سیستم در فیلدهای ساعت پایه |
| **دکمه Paste** | کلید دستی جایگزین برای خواندن کلیپ‌بورد |
| **آیکون خورشید / ماه** | جابجایی بین حالت شب (Dark Mode) و حالت روز (Light Mode) |
| **آیکون پین** | سنجاق کردن پنجره روی سایر برنامه‌ها (Always on Top) |

| **Auto-Tab** | پرش خودکار به فیلد دقیقه پس از تایپ دو رقم در بخش ساعت |

## 🕒 فرمت‌های زمانی پشتیبانی‌شده

پارسر برنامه به صورت خودکار انواع فرمت‌های خروجی اکسل و زبان‌ها را شناسایی و پالایش می‌کند:

| متن کپی‌شده | نحوه تفسیر در Clock Plus |
| :--- | :--- |
| `14:30:00` | ساعت `14` و دقیقه `30` (ثانیه نادیده گرفته می‌شود) |
| `14:30` | ساعت `14` و دقیقه `30` |
| `14-30` یا `14/30` یا `14.30` | ساعت `14` و دقیقه `30` |
| `02:30 PM` یا `02:30 ب.ظ` | تبدیل خودکار به فرمت ۲۴ ساعته: `14:30` |
| `08:15 AM` یا `08:15 ق.ظ` | ساعت `08` و دقیقه `15` |
| `1430` | ساعت `14` و دقیقه `30` (اعداد ۴ رقمی به هم چسبیده) |
| `915` | ساعت `09` و دقیقه `15` (اعداد ۳ رقمی به هم چسبیده) |
| `۱۶:۴۵` | تبدیل ارقام فارسی به انگلیسی: ساعت `16` و دقیقه `45` |
| `+01:30` | تنظیم خودکار بخش «مقدار اضافه» روی `+01:30` و محاسبه آنی |
| `-00:45` | تنظیم خودکار بخش «مقدار اضافه» روی `-00:45` (کسر زمان) و محاسبه آنی |

## ⚙️ پایداری و تنظیمات (timecalc_settings.json)

تنظیمات برنامه در یک فایل سبک JSON کنار فایل اجرایی ذخیره می‌شود:

```json
{
  "theme": "dark",
  "add_hour": "1",
  "add_minute": "30",
  "geometry": "560x720+595+115"
}
```

- **theme:** وضعیت تم فعال (`dark` یا `light`).
- **add_hour:** مقدار ساعت ثابتی که باید اضافه یا کم شود (پشتیبانی از اعداد منفی).
- **add_minute:** مقدار دقیقه ثابت افزایشی.
- **geometry:** آخرین مختصات قرارگیری و ابعاد پنجره روی دسکتاپ.

## 🔨 راهنمای کامپایل و بیلد با PyInstaller

اگر سورس‌کد `clock.py` را تغییر دادید و مایلید فایل اجرایی پورتابل جدید بسازید:

### پیش‌نیازها:
```bash
pip install pillow pyperclip pyinstaller
```

### دستور بیلد تک‌فایل مستقل:
```bash
python -m PyInstaller \
  --noconsole \
  --onefile \
  --icon="icon.ico" \
  --add-data="icon.ico;." \
  --name="ClockPlus" \
  --clean \
  clock.py
```

- خروجی نهایی: `D:\sp2l excel\Clock Plus\ClockPlus.exe`
- حجم فایل اجرایی نهایی: حدود ۱۶ مگابایت (شامل مفسر کامل پایتون، Tkinter و کتابخانه‌ها به صورت تک‌فایل بدون نیاز به نصب).
